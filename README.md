
# ÉLORA – Luxury E-Commerce Storefront

## About the Project

ÉLORA is a modern luxury-inspired e-commerce storefront developed as part of a hands-on project engineering internship.

The application allows users to browse products, explore product details, search and filter products, manage a shopping cart, and complete a demonstration checkout process.

The project focuses on creating a clean, responsive and user-friendly online shopping experience.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality
- FakeStoreAPI – Product data and information
- LocalStorage – Persistent shopping cart data
- Git and GitHub – Version control and project hosting

## Features

- Dynamic product catalogue
- Product information and images retrieved from FakeStoreAPI
- Product search functionality
- Category filtering
- Individual product details
- Interactive shopping cart
- Add and remove products
- Increase and decrease product quantities
- Automatic subtotal, tax and shipping calculations
- Persistent cart using LocalStorage
- Checkout form with customer details
- Demonstration order confirmation

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Tintswalo15/elora-ecommerce-store.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd elora-ecommerce-store
```

### 3. Run the application

Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.

## API Integration

This project uses FakeStoreAPI to retrieve product information, including product names, prices, categories, descriptions and images.

API endpoint:

https://fakestoreapi.com/products

## Important Note

The checkout functionality is a demonstration. It does not process real payments or create actual purchases.
